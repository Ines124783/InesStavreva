## Описание

Уеб базирана информационна система за управление на хотелски резервации,
разработена за условен морски курортен хотел „Лазур" с категория 4 звезди
и 32 стаи.

Системата автоматизира процесите по управление на резервации, гости и стаи,
като предоставя интуитивен интерфейс за гостите и административния персонал.

## Инсталиране

### Изисквания
- PHP 8.3+
- Composer
- MySQL 8.0+
- Node.js (опционално)

### Стъпки

**1. Клониране на репото**
```bash
git clone https://github.com/твоето-потребителско-име/hotel-lazur.git
cd hotel-lazur
```

**2. Инсталиране на зависимостите**
```bash
composer install
```

**3. Конфигурация**
```bash
cp .env.example .env
php artisan key:generate
```

**4. Настройка на базата данни**

Редактирай `.env` файла:
```
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=hotel_lazur
DB_USERNAME=root
DB_PASSWORD=
```

**5. Изпълнение на миграциите**
```bash
php artisan migrate
```

**6. Стартиране**
```bash
php artisan serve --port=80
```

Отвори http://127.0.0.1/ в браузъра.

## Функционалности

### Публична част (гости)
- Преглед на наличните стаи
- Проверка на наличност по период
- Онлайн резервация
- Регистрация и вход

### Административна част (персонал)
- Управление на резервации (CRUD)
- Управление на стаи
- Управление на гости
- Ауторизация — администратори и обикновени потребители
